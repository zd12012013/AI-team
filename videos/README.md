# 🎥 Как снимать видео для разбора

## Как передать видео команде

**Прикрепи файл прямо в чат** (скрепка 📎) — я заберу его и положу сюда сам.

⚠️ **Ссылки на Google Drive, Яндекс.Диск и другие облака не работают.**
У этой сессии закрытый доступ в интернет: шлюз блокирует всё, кроме
разрешённых адресов, и `drive.google.com` в их число не входит. Дело не в
настройках доступа к папке — файл не скачается, даже если открыть его «для
всех, у кого есть ссылка».

Поэтому короткие клипы (20–60 секунд) удобны вдвойне: и разбирать их лучше,
и в чат они грузятся быстро.

## Ракурс — самое важное

| Что снимаем | Куда ставить камеру |
|---|---|
| Техника удара (справа/слева) | **Сбоку от стола, на уровне стола.** Видно тебя в полный рост, включая ноги |
| Работа ног, перемещения | Сбоку, чуть дальше — чтобы в кадр влезала вся твоя зона |
| Подача | Сбоку + чуть спереди, видно руку с мячом и момент подброса |
| Игра, тактика | Сзади-сбоку, видно обе половины стола |

## Правила, которые сильно улучшают разбор

1. **Ноги в кадре.** Без ног половина разбора отваливается — работа ног важнее рук.
2. **Камера неподвижна.** Поставь на стул, сумку, штатив. Не снимай с рук.
3. **Длина 20–60 секунд.** Лучше три коротких клипа про разное, чем один пятиминутный.
4. **Один клип в замедленной съёмке** (slow-motion 120/240 fps) — там видно точку контакта.
5. **Свет в спину камере**, не в объектив, иначе ты получишься тёмным силуэтом.
6. **Имя файла говорящее:** `2026-07-25_forehand_multiball.mp4` — а не `IMG_4821.mp4`.

## Что снимать, если не знаешь, с чего начать

- 30 секунд многомячки справа (топспин по подставке)
- 30 секунд многомячки слева
- 30 секунд перемещений «два справа — один слева»
- 5–6 подач подряд
- один розыгрыш в игре целиком
