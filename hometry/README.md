# 🔍 HomeTry — «Весь мир — твой учебник»

**HomeTry** — прототип образовательного стартапа для школьников 12–17 лет.
Это не AI-репетитор, а **AI Discovery Learning Platform**: обучение через исследование
окружающего мира.

Ученик выбирает школьный предмет (история, физика, химия, биология, география,
математика, литература), фотографирует любую вещь вокруг себя — носок, ложку, монету,
кроссовок — и HomeTry показывает, как эта вещь связана с темой урока, задаёт вопрос
и даёт мини-задание.

---

## ✨ Что умеет прототип

| Раздел | Что там |
|---|---|
| **Home** | Выбор школьного предмета (крупные карточки) + кнопка «Запустить демо» для жюри |
| **Учу тему** | После выбора предмета — список тем школьной программы (3–4 на предмет): карточка с правилом и формулой → «Найди дома» (3 вещи + опыт) → 3 вопроса → отметка «Тема изучена» |
| **Scan** | Фото с камеры телефона (`capture="environment"`) или из галереи + быстрые демо-предметы |
| **Discover** | «Обнаружено: …», связь с предметом, интересный вопрос, мини-задание, три режима |
| **Connection Chain** | Главная «вау»-часть: анимированная цепочка карточек, соединённых линиями, через несколько предметов |
| **My Discoveries** | Коллекция найденных связей и изученных тем (хранится в `localStorage`) |
| **Quiz** | 3–5 вопросов с вариантами по твоим открытиям и изученным темам |
| **Настройки** | Язык, демо/AI-режим, API-ключ Claude |

### Три режима обучения
- **DIRECT** — прямая связь: носок → текстиль → фабрики тканей → промышленная революция.
- **UNEXPECTED** — неожиданная, но логичная: ложка → рычаг → правило рычага → механика.
- **CHALLENGE** — ученик сам пишет объяснение связи, потом видит пример хорошего ответа.

### Честность фактов
- Каждый результат и каждый шаг цепочки помечены значком **📚 Факт** или **💡 Аналогия**.
- У каждого факта есть **источник** (название + ссылка). Ссылки на Википедию сделаны через
  поиск (`…/w/index.php?search=…&go=Go`) — так они не «ломаются», даже если статья
  переименована. Задача проверяющего факты — по возможности заменить их на прямые ссылки.
- Конкретные даты указаны только там, где они общеизвестны (например, тенге — ноябрь 1993,
  независимость Казахстана — 16 декабря 1991). В остальных случаях — общие формулировки.
- Скрипт `tools/sync-data.py` не даст сохранить факт без источника.

## 🚀 Как запустить

### Вариант 1 — просто открыть
Дважды кликни по `index.html`. Всё работает без интернета и без установки:
данные подгружаются из `data/data-fallback.js`.

### Вариант 2 — через локальный сервер (как на настоящем сайте)
```bash
cd hometry
python3 -m http.server 8000
```
Открой в браузере `http://localhost:8000`. Чтобы проверить с телефона, подключи его к той же
Wi‑Fi сети и открой `http://IP-компьютера:8000`.

> Камера телефона через `input type="file" capture` работает и по http, и по https.

## 🌐 Как включить GitHub Pages

1. Залей репозиторий на GitHub.
2. Открой **Settings → Pages**.
3. В **Build and deployment → Source** выбери **Deploy from a branch**.
4. Выбери ветку (например, `main`) и папку **`/ (root)`** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://<твой-логин>.github.io/<имя-репозитория>/hometry/`.

Хочешь, чтобы сайт открывался прямо по `https://<логин>.github.io/<репозиторий>/`?
Перенеси содержимое папки `hometry/` в отдельный репозиторий (в его корень) — сборка не нужна.

## ➕ Как добавить новую вещь в `objects.json`

1. Открой `data/objects.json` и добавь в массив `objects` новый блок по образцу:

```json
{
  "id": "cup",
  "name": "Кружка",
  "emoji": "☕",
  "aliases": ["кружка", "чашка", "cup"],
  "topics": {
    "physics": {
      "direct": {
        "title": "Почему чай остывает",
        "badge": "fact",
        "text": "2–4 простых предложения о связи.",
        "source": { "title": "Википедия — «Теплопередача»", "url": "https://ru.wikipedia.org/w/index.php?search=Теплопередача&go=Go" },
        "question": "Интересный вопрос ученику?",
        "task": "Мини-задание на 5–15 минут.",
        "chain": [
          { "subject": "physics", "badge": "fact", "label": "Кружка", "text": "Одно короткое предложение." },
          { "subject": "physics", "badge": "fact", "label": "Теплопередача", "text": "…" },
          { "subject": "chemistry", "badge": "analogy", "label": "…", "text": "…" }
        ]
      },
      "unexpected": { "…": "та же структура, что у direct" },
      "challenge": {
        "question": "Вопрос, на который ученик отвечает сам",
        "hint": "Подсказка",
        "sample": "Пример хорошего ответа",
        "badge": "fact",
        "source": { "title": "…", "url": "…" }
      },
      "quiz": [
        { "q": "Вопрос?", "options": ["Верный", "Неверный", "Неверный", "Неверный"], "answer": 0, "explain": "Почему." }
      ]
    }
  }
}
```

2. Правила:
   - `subject` — только `history`, `physics`, `chemistry`, `biology`, `geography`, `math`, `literature`.
   - `badge`: `"fact"` — научный/исторический факт (тогда `source` **обязателен**);
     `"analogy"` — логическая связь (тогда `source` может быть `null`).
   - `answer` — номер правильного варианта, считая с 0. На экране варианты перемешиваются,
     поэтому правильный можно всегда ставить первым.
   - В цепочке 3–5 шагов: первый — сама вещь, последний — большая идея.
   - Не выдумывай даты и числа. Сомневаешься — пиши «в XIX веке», «по мнению учёных».
   - Чтобы вещь появилась в разделе Scan, достаточно заполнить хотя бы один предмет,
     но для демо лучше заполнить все семь.

3. Запусти проверку и обнови копию данных:
```bash
python3 tools/sync-data.py
```

Тема для режима «Учу тему» добавляется так же в `data/topics.json`: поля `id`, `subject`,
`title`, `rule`, `key` (`label`, `text`, `note`), `source`, `findAtHome` (ровно 3 вещи:
`emoji`, `name`, `how`, необязательный `objectId` для кнопки «Исследовать»),
`experiment` (`title`, `steps`, `observe`) и `quiz` (ровно 3 вопроса).

## 🤖 AI-режим (необязательный)

По умолчанию сайт работает в **демо-режиме** — без интернета и ключей. Ученик выбирает
из списка, что на фото.

В **Настройках** можно включить AI-режим и вставить свой API-ключ Claude
(получить: <https://console.anthropic.com>). Тогда:
- фото уменьшается до 1024 px и отправляется **прямо из браузера** в `api.anthropic.com`;
- Claude распознаёт вещь и возвращает связь **в том же JSON-формате**, что и `objects.json`
  (используются структурированные ответы по JSON-схеме);
- если факт пришёл без источника, сайт автоматически превращает его в «💡 Аналогию».

Системный промпт лежит в `js/ai.js` (`AI_SYSTEM_PROMPT`). Он требует разделять факты и
аналогии, давать источник для каждого факта и не выдумывать даты, числа и цитаты.

⚠️ Ключ хранится только в `localStorage` этого браузера. Не вводи ключ на чужом компьютере
и не публикуй сайт с ключом внутри кода. Каждый запрос оплачивается с аккаунта владельца
ключа. Модель по умолчанию — Claude Opus 5.5, в настройках можно выбрать более дешёвые
Sonnet 5.5 или Haiku 5.5.

## 🌍 Языки

Все тексты интерфейса — в `js/i18n.js`. Чтобы добавить или доперевести казахский,
заполни блок `kk` (ключи те же, что в `ru`). Чего нет в переводе — показывается по-русски.
Казахская версия сейчас — черновик, её нужно проверить носителю языка.
Контент (`objects.json`, `topics.json`) пока только на русском.

## 👥 Команда (6 ролей)

| Роль | За что отвечает |
|---|---|
| **Руководитель и презентация** | План на 4 дня, распределение задач, сценарий показа жюри (кнопка «Запустить демо»), питч и ответы на вопросы |
| **Дизайн** | Цвета, иконки, логотип HOMETRY, вид Connection Chain, скриншоты для презентации (`css/style.css`) |
| **Интерфейс** | Разделы сайта, удобство на телефоне, переводы (`index.html`, `js/app.js`, `js/i18n.js`) |
| **AI и логика** | Формат данных, AI-режим и системный промпт, квиз (`js/ai.js`, `data/*.json`, `tools/sync-data.py`) |
| **Проверка фактов** | Сверка каждого «📚 Факта» с источником, замена поисковых ссылок на прямые, правка формулировок, решение «факт или аналогия» |
| **Тестирование на учениках** | Показ сайта 5–10 школьникам, сбор отзывов (что непонятно, что понравилось), список багов, запуск `tests/smoke.js` |
