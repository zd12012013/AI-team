# ✦ NOVA — школьная программа Казахстана

Одна страница `index.html` без сборки и серверной части. Открывается двойным кликом (file://) или через любой статический сервер.

**Путь ученика:** Предмет → Класс → Тема (объяснение + 4 уровня: Лёгкий, Средний, Сложный, Олимпиадный) → Тест.
Тест засчитан при результате ≥ 70%. Прогресс (галочки, % по классу и предмету) хранится в `localStorage` с префиксом `nova.`.

## Предметы

| Предмет | Классы | Файл |
|---|---|---|
| Математика | 5–6 | `data/math.json` |
| Алгебра, Геометрия, Физика, Химия, Биология, География | 7–11 | `data/<id>.json` |
| Информатика, Английский язык, История Казахстана | 5–11 | `informatics`, `english`, `history_kz` |

Всего 10 предметов, 388 тем, 4 659 вопросов (минимум 3 вопроса на каждый уровень каждой темы).

## Формат данных

```json
{
  "id": "physics", "name": "Физика", "program": "…",
  "classes": {
    "7": { "sections": [ { "title": "Раздел", "topics": [ {
      "id": "p7-density", "title": "Плотность", "explain": "Простое объяснение…",
      "formula": "ρ = m / V", "check": true,
      "levels": {
        "easy":     [ { "q": "Вопрос", "o": ["верный", "неверный", "…"], "a": 0, "e": "Пояснение" } ],
        "medium":   [ … ], "hard": [ … ], "olympiad": [ … ]
      }
    } ] } ] }
  }
}
```

- `a` — индекс верного варианта (в интерфейсе варианты перемешиваются).
- `e` — пояснение. Его показывают при ошибке, и с него начинает помощник «🤖 Объясни».
- `"check": true` ставится на тему, в которой нужно сверить с учебником класс или формулировку. В интерфейсе такая тема помечена.

## Как добавить или исправить тему

1. Отредактируйте `data/<предмет>.json`.
2. Запустите проверку и пересборку:
   ```bash
   python3 tools/build-data.py
   ```
   Скрипт проверяет структуру: классы, уникальность id, не меньше 3 вопросов на уровень, корректный `a` и отсутствие повторяющихся вариантов. Затем он обновляет `data/index.json` и копии `data/js/*.js`, которые нужны для работы через file://.

## Информатика на C++

Темы программирования (7–11 классы) написаны на C++: у темы есть примеры `examples` (`title`, `code`, `out`, `in`), а у вопроса может быть поле `code`. Каждый пример и вопрос проверяется компилятором:

```bash
python3 tools/check-cpp.py   # g++ -std=c++17: компиляция + сверка вывода с ответом
```

Поле `wrap` задаёт, как дополнить фрагмент до программы (`main`, `top`, `full`), а `test` — что проверять: `out` (вывод = верный вариант), `fill` (верный вариант вместо `___`, вывод = `expect`), `compile_error` или `none`.

## NOVA AI — бесплатный помощник в браузере

Кнопка **🤖 NOVA AI** есть на каждой странице (справа внизу). Код помощника лежит в `js/ai.js`.

- Модель **Qwen2.5-1.5B-Instruct** (q4f16, для видеокарт без f16 — q4f32) работает прямо в браузере через [WebLLM](https://github.com/mlc-ai/web-llm) `@mlc-ai/web-llm@0.2.87` с CDN jsDelivr. Ключи и серверы не нужны.
- Модель загружается при первом открытии чата (~1 ГБ, с прогресс-баром), дальше берётся из кэша браузера.
- Помощник знает контекст: предмет, класс, тему (её объяснение из `data/*.json` добавляется в промпт), текущий вопрос, ответ ученика и ошибки в тесте.
- Сначала даёт подсказки, полное решение — по кнопке «Покажи решение». Быстрые кнопки: «Объясни проще», «Дай пример», «Проверь моё решение», «Похожая задача».
- Ответ появляется по мере генерации, с форматированием и подсветкой C++. Под каждым ответом: «ИИ может ошибаться — проверяй по учебнику».
- **Без WebGPU** (или если модель не загрузилась) включается **упрощённый режим**: ответы из объяснений тем NOVA и кратких статей Википедии (API extracts).

## Лимит и тарифы (демо)

- Бесплатно — 20 сообщений NOVA AI в день. Счётчик хранится в `localStorage` (`nova.ai.usage`) и обнуляется в полночь; над чатом написано «Осталось сегодня: N».
- Когда лимит кончился, в чате появляется карточка «Лимит на сегодня исчерпан» с кнопкой «NOVA Premium».
- Страница `#/premium` сравнивает Free / Premium / Школа. Это демо для презентации без настоящей оплаты: кнопка «Попробовать Premium (демо)» снимает лимит. Код — `js/limit.js`.

## Языки: РУС | ҚАЗ

- Переключатель «РУС | ҚАЗ» есть в шапке и в Настройках, выбор хранится в `localStorage` (`nova.lang`). Код — `js/i18n.js`.
- Интерфейс переводится функцией `tr("Русская фраза")` через словарь `KZ_UI`. NOVA AI и Premium хранят свои фразы в `js/ai.js` и `js/limit.js`.
- **Учебные данные.** Русский текст лежит в основных полях, казахский — в объекте `kz` того же узла:
  ```json
  { "title": "Плотность", "explain": "…", "kz": { "title": "Тығыздық", "explain": "…" }, "kz_check": true,
    "levels": { "easy": [ { "q": "…", "o": ["…"], "e": "…", "kz": { "q": "…", "o": ["…"], "e": "…" }, "kz_check": true } ] } }
  ```
  `kz_check: true` значит, что перевод ещё должен проверить носитель языка. Порядок вариантов в `kz.o` совпадает с `o`. Если перевода нет, показывается русский текст с пометкой «аудармасы жоқ».
