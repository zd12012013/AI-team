# 🏓 Моя ИИ-команда по настольному теннису

Пять тренеров разбирают видео моих тренировок и игр, дают задания
и следят за прогрессом от разбора к разбору.

## Как этим пользоваться

1. Сними видео (как — написано в [`videos/README.md`](videos/README.md)).
2. Положи файл в папку `videos/`.
3. Напиши мне: **«разбери videos/имя_файла.mp4»** — или просто «разбери
   новое видео», если оно там одно.
4. Получишь разбор и три задания. Отчёт сохранится в `reports/`.

Через несколько тренировок спроси: **«покажи мой прогресс»** — команда
сравнит все отчёты и скажет, что улучшилось, а что ещё западает.

## Что где лежит

| Папка | Что там |
|---|---|
| `videos/` | Твои видео (в git не сохраняются — тяжёлые) |
| `frames/` | Кадры и раскадровки, генерируются автоматически |
| `reports/` | **Память команды** — все разборы, по одному файлу на тренировку |
| `scripts/` | Служебные скрипты для нарезки кадров |
| `CLAUDE.md` | Инструкция для команды: кто вы, как разбирать, как писать |

## Команда

| Специалист | За что отвечает |
|---|---|
| 🎯 Технический тренер | Замах, точка контакта, угол ракетки, завершение |
| 👟 Аналитик движения | Ноги, стойка, сплит-степ, баланс, возврат в позицию |
| ♟ Тактик | Выбор мяча, позиция у стола, схемы розыгрышей |
| 🦴 Биомеханик | Цепь «ноги → корпус → рука», перенос веса, нагрузка на суставы |
| 📈 Аналитик прогресса | Сравнение с прошлыми отчётами |

## Скрипты (обычно запускает команда сама)

```bash
bash scripts/setup.sh                          # поставить ffmpeg + imagemagick
bash scripts/prep.sh videos/forehand.mp4 [fps] # кадры + раскадровки
bash scripts/zoom.sh frames/forehand/f_042.jpg bottom  # укрупнить кадр
```
